# Koji — JLPT Study Agent

自分の教材と使いやすい言語で、JLPT N5〜N1を学習できます。難しい問題を解決し、今日の時間に合った課題を選び、前回の続きから再開しましょう。

## 質問から始める

**普段使っているAIチャットで：** [Kojiガイド](../agent/COACH.md)をアップロードするか貼り付けてから、質問を送ってください。必要に応じて該当する文、選択肢、自分の答えを添えます。短い抜粋や、チャットで読み取れる鮮明な写真を使ってください。

> このKojiガイドに従って、日本語で説明して。私はBを選んだけど、解答ではCになっている。本文と私の考え方を送るので、なぜCのほうが適切なのか教えて。

**ファイルにアクセスできるCodexまたはClaude Codeで：** [リポジトリをダウンロード](https://github.com/youngtak-k/koji-jlpt-study-agent/archive/refs/heads/main.zip)し、解凍してフォルダーを開きます。次のように頼んでください。

> AGENTS.mdを読んで、Kojiでの勉強を手伝って。説明と私のノートは日本語にして。教材の質問を送るね。

どちらの依頼も、自分の言語で書けます。Koji用のサーバー、専用アプリ、Pythonのインストール、プロジェクト用APIキーは不要です。ガイドを読めるAIアシスタントへのアクセスが必要で、そのサービスの利用制限や料金は適用されます。

## 今日の課題を選ぶ

教材のどこを開いているか、何分使えるかを伝えてください。目標のJLPTレベルがまだ伝わっていなければ、それも添えます。

> N3を目指している。この文法セクションの最初にいて、今日は25分ある。今日やることを決めるのを手伝って。

Kojiは開始位置、終了位置、復習・質問・短い振り返りを含めた時間配分を提案します。教材名だけではページや内容を特定できません。試験までの全体計画を立てる前に、ひとつのセクションから始められます。

## ひと言で終える

> 問題1〜4を18分で終えた。3番はヒントが必要だった。次は5番。

Kojiは実際に取り組んだ内容、まだ不確かな点、再開位置をまとめます。質問しただけで誤答とは扱わず、ヒント付きの正答と自力の正答を区別します。

ファイルアクセスが機能している場合、Kojiは現在の記録を `local/CURRENT.md` に保存して確認し、補足のセッションノートも残します。通常のチャットでは、自分で保存できる簡潔な更新済み学習ノートを渡します。ノートの生成は、ローカルへの自動保存ではありません。

## 戻って続きを学ぶ

> 続きをやろう。今日は15分ある。

同じ学習フォルダーを使うか、新しいチャットに最新の保存済みノートを渡してください。Kojiは関連する過去の記録を使い、短い復習と次の教材課題を提案します。たとえば、ヒントで理解した違いを、先へ進む前に自力で判断できるか短く確認します。

休んだ後は、そのまま伝えてください。

> 1週間勉強できなかった。今日は10分ある。

Kojiは確認済みの進捗から始め、時間に合うよう課題を減らします。休んだ日数が、必須の追加学習時間として積み上がることはありません。週の振り返り、記録の修正、現在のノートの書き出しを頼んだり、「このセッションは保存しないで」と伝えたりもできます。

## 学習とともに育つノート

ガイドは種麹で、学習がその材料になります。繰り返し役立つ説明は、実際に答えられたという根拠とは分けて、関連する知識ページに育てられます。自分でフォルダーを整理したり、もう一冊のノートを管理したりする必要はありません。

学習ファイルは、標準でGitの対象外になっている `local/` に保存されます。Kojiの更新時にはこのフォルダーを残し、学習記録ではなく共有ガイドのファイルを置き換えてください。ローカル保存は、AIがオフラインで処理することを意味しません。Kojiは会話中に動作し、バックグラウンド通知やコピー間の自動同期は行いません。

説明とノートは希望の言語に合わせ、日本語例文と漢字の読みを添えます。ガイドは英語で書かれています。READMEの翻訳はAIが作成し、独立したネイティブ話者の確認を受けていません。英語版が基準です。
