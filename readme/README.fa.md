# Koji — JLPT Study Agent

با کتاب خودتان و به زبان دلخواهتان برای JLPT از N5 تا N1 مطالعه کنید. سؤال‌های سخت را بفهمید، کاری متناسب با وقت امروز انتخاب کنید و دفعه بعد از همان‌جا ادامه دهید.

## با یک سؤال شروع کنید

**در گفت‌وگوی هوش مصنوعی که از قبل استفاده می‌کنید:** [راهنمای Koji](../agent/COACH.md) را بارگذاری یا جای‌گذاری کنید، سپس سؤالتان را بفرستید. در صورت نیاز جمله مربوط، گزینه‌ها و پاسخ خودتان را اضافه کنید. از یک بخش کوتاه متن یا عکس خوانایی استفاده کنید که محیط گفت‌وگو بتواند پردازش کند.

> از این راهنمای Koji پیروی کن و به فارسی توضیح بده. من B را انتخاب کردم، ولی پاسخ‌نامه C را درست می‌داند. این متن و استدلال من است. چرا C مناسب‌تر است؟

**در Codex یا Claude Code با دسترسی به فایل‌ها:** [این مخزن را دانلود کنید](https://github.com/youngtak-k/koji-jlpt-study-agent/archive/refs/heads/main.zip)، از حالت فشرده خارج کنید و پوشه را باز کنید. سپس بگویید:

> AGENTS.md را بخوان و کمک کن با Koji درس بخوانم. به فارسی توضیح بده و یادداشت‌هایم را به فارسی نگه دار. این سؤال من از کتاب است.

هر دو درخواست را می‌توانید به زبان خودتان بنویسید. به سرور Koji، برنامه جداگانه، نصب Python یا کلید API پروژه نیازی نیست. باید به یک دستیار هوش مصنوعی که بتواند راهنما را بخواند دسترسی داشته باشید؛ محدودیت‌ها و هزینه‌های آن همچنان اعمال می‌شود.

## یا کار امروز را انتخاب کنید

به Koji بگویید کدام بخش کتاب باز است و چقدر وقت دارید. اگر سطح هدف JLPT هنوز معلوم نیست، آن را هم اضافه کنید.

> برای N3 آماده می‌شوم. ابتدای این بخش دستور زبان هستم و ۲۵ دقیقه وقت دارم. کمک کن کار امروز را انتخاب کنم.

Koji نقطه شروع، نقطه پایان و تقسیم زمانی شامل مرور، سؤال و جمع‌بندی کوتاه پیشنهاد می‌دهد. عنوان کتاب به‌تنهایی برای تشخیص صفحه‌ها یا محتوای آن کافی نیست. می‌توانید پیش از برنامه‌ریزی برای کل آزمون از یک بخش شروع کنید.

## با یک پیام تمام کنید

> سؤال‌های ۱ تا ۴ را در ۱۸ دقیقه تمام کردم. برای سؤال ۳ به راهنمایی نیاز داشتم. بعدی سؤال ۵ است.

Koji خلاصه می‌کند که واقعاً چه کرده‌اید، چه چیزی هنوز نامطمئن است و از کجا باید ادامه دهید. سؤال پرسیدن خودکار خطا حساب نمی‌شود؛ پاسخ با راهنمایی از پاسخ مستقل جدا می‌ماند.

وقتی دسترسی به فایل‌ها درست کار می‌کند، Koji رکورد فعلی شما را در `local/CURRENT.md` ذخیره و بررسی می‌کند و یادداشت‌های پشتیبان جلسه را هم نگه می‌دارد. در گفت‌وگوی معمولی، یک یادداشت درسی کوتاه و به‌روز می‌دهد تا خودتان ذخیره کنید. تولید یادداشت به معنای ذخیره خودکار آن روی دستگاه شما نیست.

## برگردید و ادامه دهید

> ادامه بدهیم. امروز ۱۵ دقیقه وقت دارم.

همان پوشه مطالعه را نگه دارید یا آخرین یادداشت ذخیره‌شده را در گفت‌وگوی جدید ارائه کنید. Koji از شواهد مرتبط قبلی برای پیشنهاد مرور کوتاه و کار بعدی کتاب استفاده می‌کند. مثلاً پیش از ادامه می‌تواند خیلی کوتاه بررسی کند آیا تفاوتی را که با راهنمایی فهمیده بودید حالا مستقل تشخیص می‌دهید.

پس از وقفه، همان را بگویید:

> یک هفته درس نخواندم. امروز ۱۰ دقیقه وقت دارم.

Koji از پیشرفت تأییدشده شروع می‌کند و کار را متناسب با زمان کوچک‌تر می‌کند. روزهای ازدست‌رفته به ساعت‌های اجباری اضافه برای جبران تبدیل نمی‌شوند. می‌توانید مرور هفتگی بخواهید، رکوردی را اصلاح کنید، یادداشت فعلی را خروجی بگیرید یا بگویید «این جلسه را ذخیره نکن».

## یادداشت‌ها با مطالعه شما رشد می‌کنند

راهنما مایه تخمیر است و مطالعه شما مواد آن را فراهم می‌کند. توضیحات مفیدی که تکرار می‌شوند می‌توانند به صفحه‌های دانش مرتبط تبدیل شوند، جدا از شواهد اینکه به چه چیزی می‌توانید پاسخ دهید. لازم نیست خودتان پوشه‌ها را مرتب کنید یا دفتر دومی نگه دارید.

فایل‌های مطالعه زیر `local/` می‌مانند که به‌طور پیش‌فرض از Git مستثناست. هنگام به‌روزرسانی Koji این پوشه را نگه دارید؛ فایل‌های راهنمای مشترک را جایگزین کنید، نه سوابق یادگیری را. ذخیره‌سازی محلی به معنای پردازش آفلاین هوش مصنوعی نیست. Koji هنگام گفت‌وگو کار می‌کند و یادآوری پس‌زمینه یا همگام‌سازی خودکار بین نسخه‌ها ندارد.

توضیحات و یادداشت‌ها از ترجیحات زبانی شما پیروی می‌کنند و مثال‌های ژاپنی و شیوه خواندن کانجی را دارند. راهنما به انگلیسی نوشته شده است. ترجمه‌های README را هوش مصنوعی نوشته و گویشوران بومی به‌صورت مستقل بازبینی نکرده‌اند؛ نسخه انگلیسی مرجع است.
