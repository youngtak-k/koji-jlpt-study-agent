# Koji — JLPT Study Agent

내 교재와 내 언어로 JLPT N5–N1을 공부하세요. 어려운 문제를 해결하고, 오늘 가능한 시간에 맞는 공부를 고르고, 지난번에 멈춘 곳에서 이어갈 수 있습니다.

## 질문부터 시작하기

**기존 AI 채팅에서:** [Koji 가이드](../agent/COACH.md)를 업로드하거나 붙여 넣은 뒤 질문하세요. 필요하면 관련 문장, 선택지, 내가 고른 답도 함께 보내세요. 채팅에서 처리할 수 있는 짧은 발췌문이나 읽기 쉬운 사진을 사용하면 됩니다.

> 이 Koji 가이드를 따라줘. 한국어로 설명해줘. 나는 B를 골랐는데 정답지는 C라고 해. 지문과 내가 이렇게 생각한 이유를 보낼게. 왜 C가 더 적절해?

**파일에 접근할 수 있는 Codex 또는 Claude Code에서:** [저장소를 다운로드](https://github.com/youngtak-k/koji-jlpt-study-agent/archive/refs/heads/main.zip)하고 압축을 푼 뒤 폴더를 여세요. 이렇게 요청합니다.

> AGENTS.md를 읽고 Koji로 공부할 수 있게 도와줘. 설명과 내 노트는 한국어로 해줘. 교재에서 궁금한 문제를 보낼게.

어느 요청이든 자신의 언어로 말해도 됩니다. Koji 서버, 별도 앱, Python 설치, 프로젝트 API 키는 필요하지 않습니다. 가이드를 읽을 수 있는 AI 어시스턴트를 이용할 수 있어야 하며, 해당 서비스의 사용 한도와 비용은 적용됩니다.

## 오늘 할 공부 고르기

책의 어느 부분을 펼쳤는지, 시간이 얼마나 있는지 알려주세요. 아직 알려주지 않았다면 목표 JLPT 급수도 덧붙이세요.

> N3를 준비하고 있어. 이 문법 단원을 시작하는데 오늘은 25분 있어. 오늘 할 공부를 정해줘.

Koji는 시작점, 종료점, 복습·질문·짧은 마무리를 포함한 시간 배분을 제안합니다. 책 제목만으로 페이지나 내용을 알 수는 없습니다. 시험 전체 계획을 세우기 전에 한 단원부터 시작해도 됩니다.

## 메시지 하나로 마무리하기

> 1~4번을 18분 동안 풀었어. 3번은 힌트가 필요했어. 다음은 5번이야.

Koji는 실제로 한 공부, 아직 확실하지 않은 부분, 다음에 이어갈 위치를 정리합니다. 질문했다고 자동으로 오답 처리하지 않으며, 힌트로 맞힌 답과 혼자 맞힌 답은 구분합니다.

파일 접근이 정상 작동하면 Koji는 `local/CURRENT.md`에 현재 기록을 저장하고 확인하며, 세션 노트도 남깁니다. 일반 채팅에서는 직접 저장할 수 있도록 간결하게 갱신한 학습 노트를 제공합니다. 노트를 생성했다고 로컬에 자동 저장된 것은 아닙니다.

## 다시 와서 이어가기

> 이어서 하자. 오늘은 15분 있어.

같은 학습 폴더를 유지하거나 새 채팅에 가장 최근에 저장한 노트를 제공하세요. Koji는 관련 있는 이전 근거를 사용해 짧은 복습과 다음 교재 과제를 제안합니다. 예를 들어 힌트로 이해했던 표현의 차이를 다음 진도 전에 혼자 구별할 수 있는지 짧게 확인할 수 있습니다.

쉬었다면 그대로 말하세요.

> 일주일 쉬었어. 오늘은 10분 있어.

Koji는 확인된 진도부터 시작하고 시간에 맞게 과제를 줄입니다. 빠진 날이 의무적으로 보충해야 할 추가 시간으로 쌓이지 않습니다. 주간 복습을 요청하거나, 기록을 정정하거나, 현재 노트를 내보내거나, “이번 세션은 저장하지 마”라고 말할 수도 있습니다.

## 공부와 함께 자라는 노트

가이드는 누룩이고, 공부는 그 재료입니다. 반복해서 도움이 되는 설명은 서로 연결된 지식 페이지가 될 수 있으며, 실제로 답할 수 있다는 근거와는 구분됩니다. 폴더를 정리하거나 두 번째 노트를 직접 관리할 필요는 없습니다.

학습 파일은 기본적으로 Git에서 제외되는 `local/` 아래에 보관됩니다. Koji를 업데이트할 때 이 폴더는 유지하세요. 학습 기록이 아니라 공용 가이드 파일을 교체하면 됩니다. 로컬 저장이 AI의 오프라인 처리를 의미하지는 않습니다. Koji는 대화 중에 작동하며, 백그라운드 알림이나 사본 간 자동 동기화는 없습니다.

설명과 노트는 선호하는 언어를 따르며 일본어 예문과 한자 독음을 제공합니다. 가이드는 영어로 작성되어 있습니다. README 번역은 AI가 작성했으며 독립적인 원어민 검토를 받지 않았습니다. 기준은 영어판입니다.
