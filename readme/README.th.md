# Koji — JLPT Study Agent

เตรียมสอบ JLPT N5–N1 ด้วยหนังสือของคุณและภาษาที่คุณถนัด รับคำอธิบายข้อที่ยาก เลือกงานให้พอดีกับเวลาวันนี้ และกลับมาเรียนต่อจากจุดที่หยุดไว้

## เริ่มด้วยคำถาม

**ในแชต AI ที่ใช้อยู่:** อัปโหลดหรือวาง [คู่มือ Koji](../agent/COACH.md) แล้วส่งคำถาม แนบประโยค ตัวเลือก และคำตอบของคุณเมื่อจำเป็น ใช้ข้อความสั้น ๆ หรือภาพที่อ่านชัดและแชตของคุณประมวลผลได้

> ทำตามคู่มือ Koji นี้และอธิบายเป็นภาษาไทย ฉันเลือก B แต่เฉลยเป็น C นี่คือบทอ่านกับเหตุผลของฉัน ทำไม C จึงเหมาะกว่า

**ใน Codex หรือ Claude Code ที่เข้าถึงไฟล์ได้:** [ดาวน์โหลดคลังนี้](https://github.com/youngtak-k/koji-jlpt-study-agent/archive/refs/heads/main.zip) แตกไฟล์ แล้วเปิดโฟลเดอร์ จากนั้นขอว่า:

> อ่าน AGENTS.md แล้วช่วยฉันเรียนกับ Koji อธิบายและเขียนบันทึกของฉันเป็นภาษาไทย นี่คือคำถามจากหนังสือ

คุณเขียนคำขอทั้งสองแบบด้วยภาษาของตัวเองได้ ไม่ต้องมีเซิร์ฟเวอร์ Koji แอปแยก ติดตั้ง Python หรือคีย์ API ของโครงการ แต่ต้องใช้ผู้ช่วย AI ที่อ่านคู่มือได้ โดยยังอยู่ภายใต้ขีดจำกัดและค่าใช้จ่ายของบริการนั้น

## หรือเลือกสิ่งที่จะเรียนวันนี้

บอก Koji ว่าเปิดหนังสืออยู่ตรงไหนและมีเวลาเท่าไร หากยังไม่ทราบระดับ JLPT ที่ตั้งเป้าไว้ ให้บอกด้วย

> ฉันเตรียมสอบ N3 อยู่ต้นส่วนไวยากรณ์นี้ และมีเวลา 25 นาที ช่วยเลือกงานที่จะทำวันนี้ให้หน่อย

Koji เสนอจุดเริ่ม จุดหยุด และการแบ่งเวลาที่รวมการทบทวน คำถาม และสรุปสั้น ๆ ชื่อหนังสือเพียงอย่างเดียวไม่พอจะอนุมานเลขหน้าหรือเนื้อหา คุณเริ่มจากส่วนเดียวก่อนได้ แล้วค่อยวางแผนเตรียมสอบทั้งหมด

## จบด้วยข้อความเดียว

> ทำข้อ 1–4 เสร็จใน 18 นาที ข้อ 3 ต้องใช้คำใบ้ ต่อไปคือข้อ 5

Koji สรุปสิ่งที่ทำจริง สิ่งที่ยังไม่แน่ใจ และจุดที่จะกลับมาเรียนต่อ การถามไม่ได้ถูกนับว่าตอบผิดโดยอัตโนมัติ คำตอบที่ใช้คำใบ้จะแยกจากคำตอบที่คิดได้เอง

เมื่อการเข้าถึงไฟล์ทำงานได้ Koji จะบันทึกและตรวจสอบข้อมูลปัจจุบันที่ `local/CURRENT.md` พร้อมบันทึกประกอบของแต่ละครั้ง ในแชตทั่วไปจะให้บันทึกการเรียนฉบับอัปเดตแบบกระชับเพื่อให้คุณบันทึกเอง การสร้างบันทึกไม่ได้หมายความว่าบันทึกลงเครื่องแล้วโดยอัตโนมัติ

## กลับมาเรียนต่อ

> เรียนต่อกัน วันนี้มีเวลา 15 นาที

ใช้โฟลเดอร์การเรียนเดิม หรือส่งบันทึกล่าสุดที่บันทึกไว้ให้แชตใหม่ Koji ใช้หลักฐานก่อนหน้าที่เกี่ยวข้องเพื่อเสนอการทบทวนสั้น ๆ และงานถัดไปในหนังสือ เช่น ก่อนเรียนต่อ อาจตรวจสั้น ๆ ว่าคุณแยกความต่างที่เคยต้องใช้คำใบ้ได้เองแล้วหรือไม่

หากเว้นช่วงไป ให้บอกตรง ๆ:

> ไม่ได้เรียนมาหนึ่งสัปดาห์ วันนี้มีเวลา 10 นาที

Koji เริ่มจากความคืบหน้าที่ยืนยันแล้วและลดงานให้พอดีกับเวลา วันที่ไม่ได้เรียนจะไม่กลายเป็นชั่วโมงชดเชยที่บังคับให้ทำเพิ่ม คุณขอทบทวนรายสัปดาห์ แก้บันทึก ส่งออกบันทึกปัจจุบัน หรือบอกว่า “ครั้งนี้ไม่ต้องบันทึก” ได้เช่นกัน

## บันทึกเติบโตไปกับการเรียน

คู่มือคือหัวเชื้อหมัก ส่วนการเรียนของคุณคือวัตถุดิบ คำอธิบายที่กลับมาใช้บ่อยและมีประโยชน์อาจกลายเป็นหน้าความรู้ที่เชื่อมโยงกัน โดยแยกจากหลักฐานว่าคุณตอบอะไรได้ คุณไม่ต้องจัดโฟลเดอร์หรือดูแลสมุดโน้ตอีกเล่มเอง

ไฟล์การเรียนอยู่ใน `local/` ซึ่งไม่นำเข้า Git โดยค่าเริ่มต้น เก็บโฟลเดอร์นี้ไว้เมื่ออัปเดต Koji และเปลี่ยนเฉพาะไฟล์คู่มือส่วนกลาง ไม่ใช่บันทึกการเรียน การเก็บบนเครื่องไม่ได้หมายความว่า AI ประมวลผลแบบออฟไลน์ Koji ทำงานระหว่างที่คุณสนทนา ไม่มีการเตือนเบื้องหลังหรือซิงค์ระหว่างสำเนาโดยอัตโนมัติ

คำอธิบายและบันทึกใช้ภาษาที่คุณต้องการ พร้อมตัวอย่างภาษาญี่ปุ่นและคำอ่านคันจิ คู่มือเขียนเป็นภาษาอังกฤษ คำแปล README เขียนโดย AI และยังไม่ได้รับการตรวจอย่างอิสระจากเจ้าของภาษา โดยใช้ฉบับภาษาอังกฤษเป็นหลักอ้างอิง
