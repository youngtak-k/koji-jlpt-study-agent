# Koji — JLPT Study Agent

למדו ל-JLPT ברמות N5–N1 עם ספר הלימוד שלכם ובשפה שלכם. קבלו עזרה בשאלה קשה, בחרו משימה שמתאימה לזמן שיש היום והמשיכו מהמקום שבו עצרתם.

## מתחילים בשאלה

**בצ׳אט עם בינה מלאכותית שכבר משתמשים בו:** העלו או הדביקו את [מדריך Koji](../agent/COACH.md), ואז שלחו את השאלה. הוסיפו לפי הצורך את המשפט הרלוונטי, האפשרויות והתשובה שלכם. השתמשו בקטע קצר או בתמונה קריאה שהצ׳אט מסוגל לעבד.

> פעל לפי מדריך Koji הזה והסבר בעברית. בחרתי B, אבל במפתח התשובות כתוב C. הנה הקטע וההיגיון שלי. למה C מתאימה יותר?

**ב-Codex או Claude Code עם גישה לקבצים:** [הורידו את המאגר הזה](https://github.com/youngtak-k/koji-jlpt-study-agent/archive/refs/heads/main.zip), חלצו את הקבצים ופתחו את התיקייה. בקשו:

> קרא את AGENTS.md ועזור לי ללמוד עם Koji. הסבר בעברית וכתוב את הרשימות שלי בעברית. הנה השאלה שלי מהספר.

את שתי הבקשות אפשר לכתוב בשפה שלכם. אין צורך בשרת Koji, באפליקציה נפרדת, בהתקנת Python או במפתח API לפרויקט. נדרשת גישה לעוזר בינה מלאכותית שמסוגל לקרוא את המדריך; מגבלות השימוש והעלויות שלו עדיין חלות.

## או בוחרים מה ללמוד היום

ספרו ל-Koji איזה חלק בספר פתוח וכמה זמן יש לכם. הוסיפו את רמת ה-JLPT שאליה אתם מכוונים אם היא עדיין לא ידועה.

> אני מתכונן ל-N3. אני בתחילת פרק הדקדוק הזה ויש לי 25 דקות. עזור לי לבחור מה ללמוד היום.

Koji מציע נקודת התחלה, נקודת סיום וחלוקת זמן שכוללת חזרה, שאלות וסיכום קצר. שם הספר לבדו אינו מספיק כדי להסיק מה העמודים או התוכן שלו. אפשר להתחיל בחלק אחד לפני שבונים תוכנית לכל הבחינה.

## מסיימים בהודעה אחת

> סיימתי את שאלות 1–4 ב-18 דקות. בשאלה 3 נזקקתי לרמז. הבאה היא שאלה 5.

Koji מסכם מה עשיתם בפועל, מה עדיין לא ברור ומהיכן להמשיך. עצם השאלה אינה נחשבת אוטומטית לטעות; תשובה עם רמז נבדלת מתשובה עצמאית.

כאשר הגישה לקבצים פועלת, Koji שומר ובודק את הרשומה הנוכחית ב-`local/CURRENT.md`, לצד הערות משלימות על המפגשים. בצ׳אט רגיל הוא נותן לכם סיכום לימוד קצר ומעודכן לשמירה עצמאית. יצירת סיכום אינה שמירה אוטומטית במחשב שלכם.

## חוזרים וממשיכים

> נמשיך. יש לי 15 דקות היום.

המשיכו להשתמש באותה תיקיית לימוד, או ספקו בצ׳אט החדש את הסיכום האחרון ששמרתם. Koji משתמש בראיות קודמות רלוונטיות כדי להציע חזרה קצרה ואת המשימה הבאה בספר. למשל, לפני שמתקדמים אפשר לבדוק בקצרה וללא עזרה הבחנה שבעבר הבנתם בעזרת רמז.

אחרי הפסקה, פשוט אמרו:

> לא למדתי במשך שבוע. יש לי 10 דקות היום.

Koji מתחיל מהתקדמות שאושרה ומקטין את המשימה כדי להתאים לזמן. ימים שהוחמצו לא הופכים לשעות השלמה נוספות שחובה לבצע. אפשר גם לבקש סקירה שבועית, לתקן רשומה, לייצא את הסיכום הנוכחי או לומר ״אל תשמור את המפגש הזה״.

## הרשימות שלכם צומחות עם הלימוד

המדריך הוא המחמצת, והלימוד שלכם מספק את חומר הגלם. הסברים שימושיים שחוזרים יכולים להפוך לדפי ידע מקושרים, בנפרד מהראיות למה שאתם מסוגלים לענות עליו. אין צורך לארגן תיקיות או לנהל בעצמכם מחברת נוספת.

קובצי הלימוד נשארים תחת `local/`, שמוחרגת מ-Git כברירת מחדל. שמרו את התיקייה הזו כשמעדכנים את Koji; החליפו את קובצי המדריך המשותף, לא את רשומות הלמידה. אחסון מקומי אינו אומר שעיבוד הבינה המלאכותית נעשה ללא חיבור לרשת. Koji עובד במהלך השיחות שלכם, בלי תזכורות ברקע או סנכרון אוטומטי בין עותקים.

ההסברים והרשימות פועלים לפי העדפות השפה שלכם, עם דוגמאות ביפנית וקריאות של קאנג׳י. המדריך כתוב באנגלית. תרגומי README נכתבו באמצעות בינה מלאכותית ולא עברו בדיקה עצמאית של דוברי שפת אם; הגרסה האנגלית היא גרסת הייחוס.
